## Import and weekly work

[Salesforce Data Export](https://help.salesforce.com/s/articleView?id=admin_exportdata.htm&language=en_US&type=0) documents object CSV exports. This build accepts Account.csv, retains all source columns and requires explicit mapping for Sales Planning scenarios and rules. [Territory Planning CSV publishing](https://help.salesforce.com/s/articleView?id=sales.territory_planning_alignments_publish_to_csv.htm&language=en_US&type=5) belongs to a different Salesforce tool and is not claimed as this import format.

The selected rituals are coverage review, capacity balancing, quota allocation, scenario comparison and plan sign-off. These are directly supported by this build's commands. No claim is made that Salesforce lacks those features or cannot answer the ten example questions.
